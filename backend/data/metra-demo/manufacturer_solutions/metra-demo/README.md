# Soluciones comerciales — corpus activo METRA-DEMO

Esta carpeta contiene los **91 manifiestos de productos comerciales del catálogo activo**, organizados por sistema y subsistema. Los ficheros IFC se referencian mediante rutas relativas desde cada JSON.

Las soluciones conservan su identidad comercial y sus asociaciones con soluciones genéricas compatibles; el contrato de clasificación y el contenido constructivo permanecen inalterados.

El catálogo no concede automáticamente derechos de visualización o descarga pública para documentos IFC. Dichos permisos se controlan en PostgreSQL por activo y revisión.
