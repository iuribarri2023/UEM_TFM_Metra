# Manufacturer logos / wordmarks

Local SVG wordmark fallbacks used by the VIVA Marketplace PoC.
They intentionally contain only the manufacturer display name so the catalogue works offline without inventing or redistributing an unverified corporate symbol.
Replace any SVG with an approved official brand asset when supplied by the manufacturer; `logo_url` is self-contained as a data URI and should be regenerated with this script.

- `thermochip.svg` — THERMOCHIP S.L.U.
- `butech.svg` — Butech
- `cidark.svg` — CIDARK
- `lignumtech.svg` — Lignum Tech
- `preinco.svg` — Prefabricados PREINCO S.L.
- `arcelormittal-bs.svg` — ArcelorMittal Building Solutions
- `egoin.svg` — Egoin S.A.
- `viguetas-navarras.svg` — Viguetas Navarras S.L.
- `porcelanosa.svg` — PORCELANOSA Grupo
- `sterchelegroup.svg` — Sterchele Group
